# GopherCon India — Website

Welcome to the official repository for the **GopherCon India** website! 🌐

This repository contains the source code for the official event website, providing attendees, speakers, and sponsors with all conference details, speaker schedules, ticket information, and updates.

🌐 **Live Website:** [https://gophercon-india-2026.netlify.app/](https://gophercon-india-2026.netlify.app/)

---

## 📌 Features

- 📅 **Schedule & Agenda:** Real-time updates on keynotes, track sessions, and workshops.
- 🎙️ **Speakers & CFP:** Speaker bios, talk abstracts, and Call for Papers details.
- 🎟️ **Ticketing:** Links and info for conference registration.
- 🤝 **Sponsor Showcase:** Highlighting event partners and sponsors.
- 📍 **Venue Details:** Location maps, accommodation info, and travel guides.
